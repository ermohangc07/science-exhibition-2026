# PictoBlox Projects

Projects: Flappy Bird, Apple Catcher using AI, Space Rocket Game

Download PictoBlox (free): https://thestempedia.com/product/pictoblox/

**Note:** PictoBlox project files (`.sb3`) will be added here once built. For now, follow the build sequence below for each project inside the PictoBlox app itself.

## 1. Flappy Bird
Build order: bird falls with gravity → jump on spacebar → one pipe scrolls left → collision = game over → pipes spawn repeatedly → score counter.

## 2. Apple Catcher using AI
Build order: get it working fully with keyboard control first → swap the "move basket" trigger for PictoBlox's AI hand-position block → falling apples spawn at random X → collision = score, miss = lose life.

**Important:** test the AI/webcam version under the actual exhibition lighting a day or two before — webcam-based detection is lighting-sensitive.

## 3. Space Rocket Game
Build order: rocket moves up/down or left/right → single obstacle appears → obstacles spawn repeatedly → add shooting mechanic → score/lives.
