# Bright Future Science Exhibition 2026

Welcome! This repo has everything your team needs to build your project for the science exhibition — starter code, guidance, and a day-by-day roadmap.

## How to use this repo

1. Find your project in the folder list below.
2. Open that folder's `README.md` — it explains the concept and what to build first.
3. Follow `docs/ROADMAP.md` for the day-by-day plan your whole class is following.
4. Check `docs/TEAM-ROLES.md` to see how to split the work across your 3 team members.

## Getting started (Python projects)

```bash
git clone <this-repo-url>
cd science-exhibition-2026/python-projects
pip install pygame requests --break-system-packages
python snake_game.py
```

## Rules for every team

- Don't just copy the starter code and turn it in — extend it, break it, understand it. That's the point.
- Keep a short build log (see `docs/TEAM-ROLES.md`) of what you tried and what failed. This matters as much as the final result.
- Ask "what if I change this number / this condition?" and try it. That's how you actually learn to code.

Good luck — build something you're proud to show off!
